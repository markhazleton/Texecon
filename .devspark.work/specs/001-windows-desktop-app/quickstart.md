# Quickstart: Development and Release Validation

1. Start the existing editor and confirm a current project loads.
2. Start the desktop shell in development mode.
3. Create a project, select image and audio folders, save, and reopen it.
4. Test both reference and managed-copy media modes.
5. Run a short preview and full MP4 render; open the result and output folder.
6. Build the signed installer and install it on a clean Windows 10/11 64-bit machine.
7. Test missing media, read-only folders, invalid JSON, cancelled render, and restart after interruption.
8. Publish release metadata and confirm the static download page, checksum, version, and installer link.
